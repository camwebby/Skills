# C4 Diagram Sequence

Use `/c4-diagram-sequence` when you have an architecture plan and context and want a polished C4-style diagram document.

The skill turns a plan into a readable sequence of diagrams: system context, container, component, dynamic, deployment, and supporting state/data/evolution views where useful. It should improve names, boundaries, diagram scope, and consistency rather than merely reformatting the plan.
